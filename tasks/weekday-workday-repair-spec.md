# 個人平日工作日修補

2026-10-21 使用者確認後實作。取代前規格「初始空班僅揭露、不修補」的範圍界限；其餘來源、鎖定、週六、評分規則不變。

## 行為與流程

固定意願／小兒 → C／AC／A → B → 週六 → 骨科最低覆蓋修補 → 個人工作日修補 → 建立工作日保護基準 → 公平性 → 最終驗證 → 輸出。

對每位有效 FT，週一至五營業日只要原始意願不是全部營業班別 off，當天骨科＋小兒至少一班。這是高於公平性分數的合法性條件，週六、休診日、原始全天休不適用。

## 修補候選

- 優先搜尋同日未鎖定骨科班的轉移，以及兩個時段的人員交換。轉出者當天至少仍一班；跨日交換也不得令原本有工作的人新變成整天空班。
- 移班／交換同層比較：先看剩餘空班筆數，再比較現有公平性向量，最後操作數；人員／日期／班別順序穩定。不能只挑首位可用員工。
- 若沒有合法移班／交換改善，才在該員工該日可用且未達骨科上限的班別新增一班。可突破個人每週軟配額，不能改應排工時分母。
- 完整組合在副本上驗證；原 off/fixed、小兒、每日兩班、骨科需求上限、最低覆蓋、週六最大 AB 配對均保留。
- 每次接受需嚴格減少空班數，且不得新增其他日期／員工的空班。禁止用移走別人的最後一班換取進展。
- 公平性優先順序仍是月非自願單節 → 月工時達成率 → 每週 AC → 每週 BC／AB 同級。消除空班可接受公平性代價，不把空班隱藏成零次單節。

## 預算、錯誤與來源

沿用每階段 20,000 候選／200 接受與後處理共享 10 秒截止期限，不另延長期限。新增階段記錄 evaluated、accepted、轉移／交換／新增接受數、停止原因與前後空班明細。未到限卻未完成為 WORKDAY_UNRESOLVED，到限為 SEARCH_LIMIT；都不能輸出部分班表，也不能宣稱輸入無解。details 含 WORKDAY_REPAIR 階段、剩餘日期／員工及限制摘要，保留最佳及原始班表快照。來源 WORKDAY_REPAIR，移轉保留 originalSource。

最終驗證同時要求原有工作日保護基準及全體符合條件的平日非空班；獨立 audit 用原始 requests 重算，不依賴正式 helper。公平性以「個人工作日修補後」為評分及每時段人數不變的基準。
